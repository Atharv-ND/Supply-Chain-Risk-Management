# 2. Project Idea

The project aims to develop an intelligent supply chain risk prediction system by integrating multiple heterogeneous datasets representing different dimensions of supply chain operations.

Unlike traditional approaches that only predict delivery delay or demand forecasting, this project incorporates external environmental, economic, political, infrastructure, disaster, transportation, and seasonal factors to generate a comprehensive shipment risk assessment.

The system will also explain why a shipment is considered risky using Explainable AI techniques.

---

# 3. Problem Statement

Modern supply chains are influenced by numerous interconnected factors including:

- Weather
- Government policies
- Infrastructure quality
- Inflation
- Fuel prices
- Natural disasters
- Public holidays

Most existing systems rely solely on internal shipment data and ignore these external influences.

The objective of this project is to integrate these heterogeneous datasets into a unified machine learning framework capable of predicting shipment risk while providing explainable insights.

---

# 4. Proposed Solution

Develop a unified AI-based Supply Chain Intelligence System capable of:

- Integrating multiple global datasets
- Predicting shipment risks
- Explaining prediction decisions
- Providing actionable recommendations

The project focuses on building a multi-risk prediction framework rather than a single-task prediction model.

---

# 5. Research Gap Identified

Existing research primarily focuses on:

- Delivery delay prediction
- Demand forecasting
- Inventory optimization
- Route optimization

Common limitations include:

- Dependence on only internal shipment data
- Ignoring governance and political factors
- Ignoring macroeconomic conditions
- Ignoring disaster events
- Lack of explainability

Our project addresses these gaps through multi-source data fusion and explainable machine learning.

# 10. Dataset Merge Strategy

The DataCo dataset will act as the master dataset.

Other datasets will be merged using temporal and geographic keys.

| Dataset | Merge Key |
|----------|-----------|
| Weather | Country + Date |
| LPI | Country + Year |
| WGI | Country + Year |
| GDP | Country + Year |
| Inflation | Country + Year |
| EM-DAT | Country + Year |
| Fuel Prices | Country + Year + Month |
| Holidays | Country + Date |
